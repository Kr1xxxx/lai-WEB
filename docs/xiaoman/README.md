## 使用规则

- 采集不等于开发授权。新的大项先问老板要不要做，字段、作用、填写方式确认后再做（D-003）。
- 记录里的勾选、必填、数值都是**老板公司当前的配置**，不是小满出厂默认，也不是来财的默认值。
- 不要照抄全部字段；同名字段要分清归属（线索/客户、公司/联系人、系统/自定义）。
- 几组容易混的概念：客户查重的**展示字段**不是判重规则；**最近联系时间**不是**最近跟进时间**；
  商机赢单、订单、回款是三种不同的“成交”口径。
- 老板已排除：企业微信、钉钉、内贸专用流程、商城/订购/额度购买/采购专用流程。2026-10-09 又排除：工作流、审批流、营销设置（不做、不再问）。
  回款、海关/报关、外部沟通维持暂缓（D-006）。
